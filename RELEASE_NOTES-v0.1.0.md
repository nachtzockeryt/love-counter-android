# Love Counter v0.1.0 — Android preview

First public preview of the Love Counter Android app.

## Included

- Live relationship counter for years, months, days, hours, minutes, and seconds
- Tap a value to switch to its total count
- Edit the start date and time from the main screen
- Dark design with a subtle heart pattern and a custom app icon
- English interface
- Start date stored locally on the device

## Install

Download `LoveCounter-v0.1.0.apk` and open it on an Android phone. Android may ask you to allow installation from the app used to open the file.

This APK is for direct installation and is not a Google Play upload. For Google Play, the app needs a release-signing setup and additional packaging and SDK changes.

The preview APK is signed with the local Android debug key used to build it. Future APK updates must be signed with the same key; keep `~/.android/debug.keystore` backed up and private.
